电视工具箱

我自费花了20亿的Token，做了电视App，免费给大家用。
        
最近用ai把常用功能整合成了一个「电视工具箱」，：阅读、电视Fm、播客、远程文件、应用管理、儿童锁、电视浏览器、TV接口，8大功能。
        
📚 阅读
TXT / EPUB / MOBI 都能看，最惊喜的是内置中英文离线朗读，断网也能听，睡前闭眼听书太舒服了
        
🎧 播客 + 📻 电视FM
播客能搜索订阅、0.5–2倍速、后台播放；全国电台按省份分类，爸妈爱听的都有
        
📁 文件 + 🧩 应用
遥控器就能复制、重命名、删文件、ADB开/关；U盘里的APK选中直接装；手机扫码还能把照片视频传到电视
        
🌐 浏览器 + 🔌内置191条Tvbox接口
电视上直接刷网页、看常用站点直播；接口一键复制，不用再折腾手机投屏
        
🔒 应用锁（家长控制）
家长密码、应用锁、每日观看时长、定时锁定、手机局域网遥控孩子拿到遥控器也进不去。
        
· 支持 Android 4.4 及以上
· 支持：电视盒子，手机，车机
